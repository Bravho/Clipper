# Notification templates (ภาษาไทย)

ไฟล์ template จริงจะอยู่ที่ `src/services/review/templates/th.ts` (pure function `renderCard(item) → { text, buttons }`)
RClipper ส่ง `card.text` ที่ render แล้วไปกับ webhook `review.created` แต่ grokbot จะ render เองจาก `item` ก็ได้ (ดู API §7.1)

**หลักของการ์ด (ตัดสินได้ใน 30 วิ)**
- บรรทัดแรก: ไอคอน type + ชื่อร้าน + รหัสเคส · บรรทัดสอง: **เหตุผลที่ส่งมา** (ข้อแรกตัวหนา) ไม่เกิน 6 บรรทัดก่อนถึงปุ่ม
- ใส่หลักฐานที่ทำให้ส่งมาด้วย (เช่น `"89 บาท" ในซับ 0:07`) จะได้ไม่ต้องเปิดดูวิดีโอทั้งคลิปเพื่อหาจุดเดียว
- ปุ่มเรียงจากซ้ายไปขวาเป็น **ทางที่น่าจะเลือก → ทางที่ปลอดภัย → เปิดเว็บ**
- `complexity=complex` → ปุ่มหลักเป็น "เปิดหน้ารีวิว" แทน "อนุมัติ"

ตัวแปรใช้รูปแบบ `{{name}}` · `{{code}}` = short_code 6 ตัว · `{{due}}` = เวลาไทยแบบอ่านง่าย ("พรุ่งนี้ 14:00")
ไอคอน: 🎬 วิดีโอ · 🎙️ เสียง · 📝 สคริปต์ · 💬 ซับ/แคปชัน · 🗨️ ตอบลูกค้า · 📦 นอกแพ็กเกจ · 🚨 ร้องเรียน · 🎞️ ฟุตเทจ QC

## A. การ์ดถึง Joe (แอป Grokbot)

### A1 · `video.v1` — วิดีโอ
```
🎬 {{shop_name}} · #{{code}}
**{{reason_1}}**{{#reason_more}} (+{{reason_more}} ข้อ){{/reason_more}}
↳ {{evidence}}
{{title}} · {{ratio}} · {{duration_s}} วิ{{#voice}} · มีเสียงพากย์{{/voice}}

AI มั่นใจ {{confidence_pct}}% · แพ็กเกจเหลือ {{clips_left}} คลิป / แก้ได้อีก {{revisions_left}} ครั้ง

[✅ อนุมัติ] [❌ ไม่ผ่าน] [✏️ แก้ในเว็บ]

```


## B. ข้อความถึงร้าน (grokbot ส่งเข้า LINE)

โทน: สุภาพ เป็นกันเอง ใช้ "ค่ะ" ตามโทนของ LINE OA (ตั้งค่าได้ใน `SHOP_VOICE_PARTICLE`)
ห้ามพูดว่า "แอดมินกำลังตรวจ AI" หรือให้ข้อมูลภายในระบบ ใช้คำว่า **"ทีมงาน"** แทน

### S1 · `shop.notice_in_review` (ไม่ตอบภายใน X นาที)
```
ได้รับงานของ{{shop_name}}แล้วค่ะ 🙏
ตอนนี้ทีมงานกำลังตรวจ{{work_th}}อยู่ เพื่อให้ข้อมูลถูกต้องที่สุด
คาดว่าจะส่งให้ได้ภายใน{{eta_text_th}}ค่ะ
```
`work_th`: วิดีโอ · เสียงพากย์ · บทพูด · ข้อความ/แคปชัน · รายละเอียดคำขอ · ไฟล์ที่ส่งมา

### S2 · `shop.notice_overdue` (เลย due)
```
ขออภัยที่ล่าช้านะคะ 🙏 งาน{{work_th}}ของ{{shop_name}}ยังอยู่ระหว่างตรวจ
ทีมงานจะรีบส่งให้โดยเร็วที่สุด และจะแจ้งทันทีเมื่อเสร็จค่ะ
```

### S3 · `delivery.ready`
```
วิดีโอของ{{shop_name}}เสร็จแล้วค่ะ 🎬
{{#captions_th}}แคปชันสำหรับโพสต์:
{{captions_th}}
{{/captions_th}}ถ้าอยากปรับตรงไหน พิมพ์บอกได้เลยค่ะ (แก้ได้อีก {{revisions_left}} ครั้งในแพ็กเกจนี้)
```

### S4 · ขอฟุตเทจใหม่ (A8 → 📩)
```
ขอบคุณสำหรับไฟล์นะคะ 🙏 มีบางไฟล์ที่ใช้ทำวิดีโอได้ไม่ดีนัก:
{{#problem_files}}• {{file_label}} — {{problem_th}}
{{/problem_files}}รบกวนส่งไฟล์ใหม่ {{needed_count}} ไฟล์ได้ไหมคะ
เคล็ดลับ: ถ่ายแนวตั้ง ที่มีแสงสว่าง และถือนิ่ง ๆ ประมาณ 5–10 วินาทีต่อช็อตค่ะ
```

### S5 · นอกแพ็กเกจ — รับงาน (A6 → 💰)
```
คำขอนี้อยู่นอกแพ็กเกจ {{package_name}} ค่ะ
ทีมงานทำให้ได้ในราคา {{extra_price}} บาท ({{extra_desc}})
ถ้าตกลง พิมพ์ "ตกลง" ได้เลยค่ะ 😊
```

### S6 · นอกแพ็กเกจ — ฟรีครั้งนี้ (A6 → 🎁)
```
ครั้งนี้ทีมงานทำให้เป็นพิเศษโดยไม่มีค่าใช้จ่ายค่ะ 🎁
(ปกติ{{over_reason_short}}จะเป็นบริการเพิ่ม) กำลังดำเนินการให้นะคะ
```

### S7 · นอกแพ็กเกจ — ไม่รับ (A6 → 🚫)
```
ขออภัยค่ะ คำขอนี้ยังไม่อยู่ในบริการที่เรามีตอนนี้
{{#alternative}}ทางเลือกที่ทำได้: {{alternative}}{{/alternative}}
ถ้ามีอะไรให้ช่วยเพิ่มเติม พิมพ์บอกได้เลยค่ะ
```

### S8 · handoff (`wants_human` / `complaint`) — ส่งทันทีที่กฎตรง ไม่ต้องรอ Joe
```
รับทราบค่ะ 🙏 เดี๋ยวทีมงานจะติดต่อกลับโดยเร็วที่สุดนะคะ
(เวลาทำการ 09:00–21:00 น.){{#after_hours}} ตอนนี้นอกเวลาทำการ ทีมงานจะตอบกลับภายใน{{eta_text_th}}ค่ะ{{/after_hours}}
```

### S9 · `review.expired`
```
ขออภัยที่ทำให้รอนานค่ะ 🙏 งาน{{work_th}}ของ{{shop_name}}ทีมงานต้องขอตรวจเพิ่มอีกนิด
ทีมงานจะติดต่อกลับเองค่ะ
```
(ระบบไม่ส่งงานให้ร้านเองเมื่อหมดอายุ และ item ที่หมดอายุจะขึ้นอยู่บนสุดของคิวในหน้าเว็บ)
