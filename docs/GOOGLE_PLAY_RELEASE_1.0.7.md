## Play Console steps

1. Open RClipper (`com.rclipper.app`) in Google Play Console.
2. Go to **Test and release > Production**.
3. Select **Create new release**.
4. Keep the existing Play App Signing configuration.
5. Upload `artifacts/google-play/RClipper-1.0.7-8-release.aab`.
6. Confirm version code `8`, version name `1.0.7`, and no blocking bundle error.
7. Enter release name `RClipper 1.0.7 (8)`.
8. Add the prepared English and Thai release notes.
9. Save the release as a draft and resolve any Console errors.
10. Review App content, Store listing, Data safety, App access, pricing/countries,
    and the pre-launch report before choosing **Send changes for review**.
11. After approval, verify the production rollout settings before starting the
    rollout.

Sending changes for review and starting a production rollout are deliberate
publishing actions and should be confirmed by the account owner at action time.
